# React Learning Repository

This repository is for practicing React and learning component-based frontend development.

## Learning Goals

- Understand React components and JSX
- Practice props and state
- Learn event handling and conditional rendering
- Explore hooks such as `useState` and `useEffect`
- Build reusable UI components
- Practice organizing frontend code

## Getting Started

The repository currently contains a README only at its root. Once a React project is added, install its dependencies from the directory containing `package.json` and start the development server using the script defined in that file.

A typical Vite-based React project uses:

```bash
npm install
npm run dev
```
